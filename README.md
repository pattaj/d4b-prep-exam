# d4b-prep-exam

This project is purely for learning purposes as part of the Master’s in Advanced Digital Technologies for Business. It serves as an exam preparation tool, utilizing a question bank to test module topics.

## Project Structure

* **`data/`**: Holds the question bank for each topic in each module.
* **`app.js`**: Contains the core JavaScript logic for the application.
* **`style.css`**: Handles the user interface (UI) styling and layout.
* **`index.html`**: The main entry point that loads the UI and calls the main app logic.

## Usage
Simply open `index.html` in your web browser to launch the application.
